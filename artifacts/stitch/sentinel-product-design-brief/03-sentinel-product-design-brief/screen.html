# Sentinel Design Brief for Google Stitch Version: 1.1 Date: 2026-03-21 Purpose: This document is a design handoff brief for Google Stitch and similar AI screen-design tools. ## 1. Product Summary **Product Name:** Sentinel **Product Type:** Privacy-first focus timer and distraction accountability desktop app. **Core Idea:** Detects idle drift during focus sessions and forces a quick intervention flow to acknowledge distractions. ## 2. Visual Direction - **Color:** Deep charcoal/graphite base, Violet/Indigo primary accent, Emerald (success/short-break), Sky/Cool Blue (long-break), Amber (warning/snooze). - **Surfaces:** Layered panels, subtle transparency, soft borders, desktop-grade depth. - **Typography:** Clean modern sans serif, premium timer numerals. ## 3. Key Screens 1. Onboarding modal 2. Main timer screen 3. Preset picker popover 4. Intervention modal 5. Session complete screen 6. Settings screen 7. Reports screen 8. Distraction history / taxonomy manager 9. Account / auth screen 10. Sleep / resume prompt 11. Corner overlay / mini window ## 4. Platform Constraints - **Platform:** Windows desktop app (WPF shell + React UI). - **Size:** Default 480x640, resizable, plus a tiny corner overlay mode. - **Style:** Desktop-native, not mobile. Avoid bottom tabs and mobile patterns.
