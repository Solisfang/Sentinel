# Contributing to Sentinel (Vibe Code Edition)

## How to Contribute
- Fork or branch from `main`.
- Use short, descriptive branch names (e.g., `feature/idle-detection`).
- Open PRs early and often. Drafts are welcome!
- Keep commits atomic and messages clear.
- Respect the "one phase at a time" rule from PROMPTS.md.

## Vibe Code Etiquette
- Prioritize clarity over cleverness.
- Leave comments for non-obvious logic.
- If you get stuck, document your thought process in the PR.
- Use the MCP servers for AI pair programming (see MCP_CONTEXT.md).
- No telemetry, no cloud dependencies—privacy is sacred.
