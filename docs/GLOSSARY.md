# Sentinel Glossary

- **Vibe Code**: Rapid, creative, context-driven coding with minimal friction.
- **MCP (Model Context Protocol)**: A protocol for connecting AI tools to local resources (DB, docs, etc.).
- **Intervention**: The modal that appears when idle/distraction is detected.
- **Idle Detection**: Monitoring user input to detect inactivity.
- **WebView2**: Microsoft’s Chromium-based web control for embedding web UIs in desktop apps.
- **SQLite**: Lightweight, local database for session logging.
- **Firebase**: Google’s cloud platform for authentication and real-time/cloud data storage.
- **Firestore**: Firebase’s scalable NoSQL cloud database for syncing session and distraction data.
- **Firebase Auth**: Firebase’s authentication service for secure user login.
- **EcoQoS**: Windows Efficiency Mode for low resource usage.
