# Sentinel Glossary

- **Vibe Code**: Rapid, creative, context-driven coding with minimal friction.
- **MCP (Model Context Protocol)**: A protocol for connecting AI tools to local resources such as databases, docs, and services.
- **Intervention**: The modal that appears when idle/distraction is detected during an active focus session.
- **Idle Detection**: Monitoring user input inactivity to detect drift away from focused work.
- **WebView2**: Microsoft's Chromium-based web control for embedding web UIs inside desktop apps.
- **SQLite**: Lightweight local database for sessions, distractions, and taxonomy data.
- **Firebase**: Google's cloud platform for authentication and cloud data storage.
- **Firestore**: Firebase's cloud database used for optional syncing of sessions and distractions.
- **Firebase Auth**: Firebase's authentication service for secure optional login.
- **EcoQoS**: Windows Efficiency Mode for low resource usage.
- **Distraction Pill**: A clickable quick-select chip in the intervention UI that lets the user reuse a recent or common distraction without typing it again.
- **Distraction Category**: A higher-level grouping for similar distractions, such as mapping Twitter and Instagram into Social Media.
- **Distraction Mapping**: The relationship between a raw distraction label and its reporting category.
- **Taxonomy**: The combined system of distraction labels, categories, and mappings used for cleaner reporting and analytics.
- **Corner Overlay**: A small always-available pop-up or mini-window that sits in a screen corner so the user can keep Sentinel visible without the full app window open.
