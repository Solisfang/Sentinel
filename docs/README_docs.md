# Sentinel Docs Folder

Welcome to the Sentinel docs folder. This is the central reference point for product direction, implementation context, setup, design handoff, and collaboration.

## What's Inside
- **PRD.md**: Product Requirements Document with core vision, workflows, and approved next enhancements
- **Plan.md**: Master implementation plan and roadmap
- **STITCH_DESIGN_BRIEF.md**: Detailed design handoff brief and prompt pack for Google Stitch / AI design generation
- **ARCHITECTURE.md**: System architecture, data flow, and planned technical additions
- **PROMPTS.md**: Copy-pasteable implementation prompts for phased vibe coding
- **PROGRESS.md**: What is already built and what is approved next but not implemented yet
- **FAQ.md**: Common questions about product behavior, privacy, setup, and planned enhancements
- **GLOSSARY.md**: Definitions of key Sentinel concepts
- **SETUP.md**: Local setup steps for backend, frontend, and Firebase
- **CONTRIBUTING.md**: Contribution guidance and collaboration etiquette
- **MCP_CONTEXT.md**: MCP and AI-pairing context

## Current Documentation Note
The docs now also track the recently completed UX enhancements:

- distraction quick-select pills using recent and top distractions
- user-manageable distraction categories and mappings
- editable historical distraction/category relationships for better reporting
- a small corner overlay / mini-window mode so the full app does not need to stay open

## Vibe Coding Philosophy
Sentinel is built for rapid, creative, privacy-first development with optional cloud sync and identity via Firebase. Use these docs to get up to speed, collaborate, and keep the product direction consistent.
