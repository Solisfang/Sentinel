# Sentinel Docs Folder

Welcome to the Sentinel docs folder! This is your one-stop resource for understanding, setting up, and contributing to the Sentinel app via true "vibe code" collaboration.


## What's Inside
- **01_PRD.md**: Product Requirements Document (core vision, workflows)
- **02_Plan.md**: Vibe coding master plan and project blueprint
- **CONTRIBUTING.md**: How to contribute, vibe code etiquette
- **SETUP.md**: Step-by-step setup for backend, frontend, and Firebase
- **MCP_CONTEXT.md**: Using Model Context Protocol servers for AI pair programming (now includes Firebase)
- **ARCHITECTURE.md**: System architecture and folder structure (now includes Firebase Auth and Firestore)
- **PROMPTS.md**: Copy-pasteable master prompts for each phase (with Firebase integration)
- **FAQ.md**: Answers to common questions (including Firebase/cloud sync)
- **GLOSSARY.md**: Definitions of key terms


## Vibe Coding Philosophy
Sentinel is built for rapid, creative, privacy-first development—with optional cloud sync and identity via Firebase. Use these docs to get up to speed, collaborate, and keep the vibe going!
